# wowhelper

Read-only helper addons for World of Warcraft: Forever (client 1.60.1, interface 16001).
Each folder is one addon; copy it into `_forever_\Interface\AddOns`.

LevelGuide's 21 zone routes are built from Forever quest data (wow4ever.quest / Questie Forever,
foreverchanges.pro): quest IDs, givers, coordinates and prerequisites. Objective spots for ordinary mobs
come from Classic wikis where the Forever sources give none; each route's header says which.
