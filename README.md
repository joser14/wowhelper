# wowhelper

Read-only helper addons for World of Warcraft: Forever (client 1.60.1, interface 16001).
Each folder is one addon; copy it into `_forever_\Interface\AddOns`.

LevelGuide's zone routes are being rebuilt from Forever quest data (wow4ever.quest / Questie Forever,
foreverchanges.pro). Rebuilt: Teldrassil, Darkshore, Ashenvale, Loch Modan, Wetlands, Duskwood, Hillsbrad,
Tanaris, Feralas, The Hinterlands, Felwood, Burning Steppes, Western and Eastern Plaguelands.
Still Classic-based: Dun Morogh, Arathi, Desolace, Stranglethorn, Un'Goro, Winterspring, Silithus.
