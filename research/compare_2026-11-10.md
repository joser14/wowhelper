# Every helper compared with the addons people use for the same job (2026-11-10)

This file is one table per installed addon. Each row says:
- which addons do the same job;
- what they have that we don't;
- where ours is better.

The bug review from the same day is in `review_2026-11-10.md`.

**How the comparison was made.** Two kinds of source, marked in the "Read" column:
- **src**: the addon's code was read earlier, read-only and never run. The write-ups are listed below.
- **pub**: only the addon's public description was used: its store page, readme and well-known behaviour. Its code
  wasn't read, so treat these rows as lower confidence.

Write-ups for the src addons:
- RestedXP: `rxp_deep.md`, `rxp_forever_guides.md`.
- Auctionator: `auctionator_deep.md`.
- Plater, QoL, VeritasUI, VoidSweep, AutoCompanion: `thirdparty*.md`.
- Polestar, Leveldon, Questdon, ForeverWisp, Guidelime, Ding, ForeverQuest, Questie: `forever_guides_survey.md`,
  `guides_deep_re.md`.

Anything that plays for you is left out on purpose and isn't counted as a gap. That covers auto-sell, auto-buy,
auto-equip, auto-train, gossip skipping, targeting macros and CVar or Blizzard-frame rewrites. AutoQuest is the one
exception the owner asked for.

## Ranked: worth building next

**Built on 2026-11-10:** items 3 (drowning), 4 (XP by source), 5 (flight times) and 6 (`/way`), plus Questie-style quest givers on the map from our routes. Still open: 1, 2, 7, 8.

Ranked by value for a solo Alliance leveler, read-only only:

1. **Horde routes and plan** from RestedXP's free Horde 1-22 facts (L). Asked to wait: Alliance first.
2. **Skyborne 1-13 step-by-step route** on Zephras Isle (M). Facts are in RestedXP's Skyborne guide.
3. **Drowning and fatigue warning** in ReadyCheck (S). The `MIRROR_TIMER_START` event plus a sound and a flash of our own frame.
4. **XP by source** in LevelLog (M): quest XP from `QUEST_TURNED_IN`, the rest counted as kills. This avoids the chat-text event, whose text can be secret.
5. **Flight times** in Landmarks (M), learned from your own flights: `PLAYER_CONTROL_LOST` while `UnitOnTaxi`, then landing.
6. **`/way x y`** through the shared waypoint (S).
7. **Travel pins** for boats, zeppelins, portals and dungeon entrances in MapPins (M, data work).
8. **Spirit-healer arrow** when you've released (M, needs our own spirit-healer positions).
